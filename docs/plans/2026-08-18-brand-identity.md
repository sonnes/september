# Implement the September brand identity

## Approved direction

- Use Lexend Bold for brand lettering only.
- Use an inverted, top-down 2D mechanical keycap as the square mark.
- Set `Sep` large inside the keycap.
- Use `September` as the wordmark, with `Sep` in indigo and `tember` in pale indigo.

## Implementation

1. Add failing tests for the brand components, assets, and primary placements.
2. Add the Lexend brand font and reusable mark and wordmark components.
3. Replace the fox asset and regenerate favicon, touch, and install icons.
4. Apply the mark and wordmark to marketing, onboarding, sidebar, mobile, desktop, and social-card branding.
5. Update the design-system documentation and run the web test, lint, and build commands.

## Out of scope

- Changing the app-wide Noto Sans interface font.
- Changing the indigo product palette.
- Redesigning non-brand UI.
