Present & Export a note

The replacement for reels. A note gets two ways out of the editor, identical on the desktop and web apps: Present — a full-screen, spoken story view for a person in the room or on a call — and Export — a dialog that saves the note as Text, Audio, or Video. The look is the decided tone system (see 2026-08-24-present-look-options.html): the Keycap tones — September's own indigo, ink, and paper — by default, with the warm Reading-light paper tints as further choices. The old reel look and its social-media noun are retired.

1 · Where it lives — the note editor header

Two new pills beside the existing Voice-over action. Present is the primary action of a finished note. No new console mode, no new rail tab, no new route — the overlay opens in place and Esc returns to the untouched editor.

2 · Present — the full-screen story view

Full-bleed colour, one chunk at a time, fitted to the screen at the largest size that fits (pretext layout). Display chunks (a heading, or the first chunk of a --- section) render bold; support chunks calm. The Keycap tones set both in Noto Sans; the Reading-light paper tints set display chunks in the Fraunces serif with a deep accent on the active word. Spoken mode reads each chunk with the user's voice and advances when playback ends; the speaker toggle switches to silent mode, where the partner simply reads.

3 · Desktop — presenting into a call

No new native code. September Microphone already carries native speech into the call, so a presented note is heard. While a presentation runs with September Camera on, the current chunk replaces the Talk draft on the camera overlay — and the Talk draft returns when the presentation closes (a deliberate, documented amendment to the “camera shows Talk text” rule).
