Existing PickList

Same rows as the OpenRouter key page today: two columns, 44px rows, a border on the chosen row, and Free or Paid at the right. The list has fewer than nine rows, so PickList shows no search field.

Fixed height

Every model list box is the same height, so the page does not jump when a list grows or a model leaves it. The box scrolls with the thin zinc scrollbar from DESIGN.md.

Two lists

Suggestions list small, quick models, because they run on every space bar. The Agent and phrases list holds stronger models. Both lists have eight rows, so PickList shows no search field.

Group headers

Frontier and Open models are new group rows in PickList. Today PickList has no groups, so this is a small addition to the block.

Who owns the list

A constant in core, reviewed each release. A saved model that is not on the list shows as a first row, "Current: model name", until the person picks another.

Switch

The shadcn Switch. packages/ui has no switch today, so it is a new primitive. The stock switch is 18px tall. The mock draws it at 24px with a 44px hit area, as DESIGN.md asks.

Decisions and open calls

AI Assistance. Provider first. Suggestions has a switch and a model. Agent and phrases share a section, a model, and two switches. The Agent is on by default. Speaking style comes last.

Model lists. Automatic, then Frontier and Open models groups, inline in the existing PickList at a fixed height. Suggestions list quick models. Agent and phrases list models that are strong at tool calls.

Voice. Expression presets with Custom. Presets move to Flash v2.5, because Turbo v2.5 is deprecated.

Settings data. The default model and the suggestions override become two models: suggestions and agent. Phrases and the new-space description read the agent model. The model lookup already takes a feature name, so the change is in the settings shape, the backup format, and the migration of saved settings.

Calls for you

  • Open weights. Make sure that each row in the Open models group has open weights.
  • Voice model migration. Saved settings with Turbo v2.5 can move to Flash v2.5 without a question, because ElevenLabs names Flash as the replacement.
