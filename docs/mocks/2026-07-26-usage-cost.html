Token & cost usage for every API call

September runs on the user's own keys. Nobody is billed by us — they're billed by Google, OpenRouter and ElevenLabs, and today they have no idea how much. This mock covers the whole surface: one meter behind every outbound call, one price table, and two screens — a calm Spend card on the dashboard and a full Usage page in Settings for the person who wants receipts.

The design rule: never show one invented dollar number. Providers bill in three different shapes, so the UI shows three, each labelled with where it came from. A user should be able to hold this screen next to their provider invoice and have it make sense.

● Measured

OpenRouter returns the exact charge for the call in its response. We store the number it gives us. No estimate, no drift.

● Estimated

Gemini reports tokens but not money. We multiply by a price table shipped in the app and stamp the result at write time.

● Quota

ElevenLabs is prepaid credits, not pay-per-call. Dollars would be a lie — we show credits used against the plan's allowance.

Architecture

One meter, one price table, one store

No new database, no server, no per-call-site bookkeeping. Two choke points cover eight of the nine paths.

1 · Call sites
  • useGenerate
  • useTranscribe
  • extractText
  • use-speech (4 engines)
  • cloneVoice

Unchanged, except for what they hand the meter.

2 · Meters
  • meterMiddleware — an AI SDK LanguageModelMiddleware. Catches every LLM call, success or failure, incl. cache hits (charged $0).
  • meterSpeech() — one wrapper in use-speech for all TTS engines.
  • One direct call for voice cloning.
3 · Pricing
  • usage/lib/pricing.ts — a plain table keyed provider:model.
  • Returns { amount_usd, source }, source ∈ measured · estimated · free · unknown.
  • Cost is stamped at write time, so history keeps the price of the day.
4 · Store & read
  • Existing analytics_events IndexedDB store, new optional cost fields — no migration.
  • useUsageSummary live-query aggregates by provider · model · feature.
  • Dashboard card, Usage page, Setup chips all read this one hook.

Three deliberate calls

Middleware, not call sites. The AI SDK already wraps every model with cacheMiddleware. Adding a second middleware means new LLM call paths are metered the day they're written, and nobody has to remember to call track(). It also fixes the current double-count: a cache hit re-reports the cached token usage today, inflating both tokens and any cost built on them.

Stamp the cost, don't compute it on read. Prices change. A call made in July should keep July's price, and the alternative — recomputing every historical event against today's table — silently rewrites history.

Three units, not one fake dollar. Tokens for LLMs, credits for ElevenLabs, free for on-device. Forcing ElevenLabs into dollars would invent a per-call price that doesn't exist on a prepaid plan.
