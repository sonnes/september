Right panel & notes navigation

Shell decided: B + M2 (icon rail, quiet header, bottom row = spaces left + modes right). Today the right panel is two different things — a settings hub in Talk, the notes navigator in Notes. Four alternatives for where notes nav lives and what the panel becomes. All frames show Notes mode.

Context: with Agent mode arriving, the panel's Context and Phrases tabs migrate to the agent's remit; History/Voice/Speech/Provider/Display remain panel candidates.

P1Toolbox panel — one consistent panel, notes list as its first tab

The panel keeps one identity across modes: an icon tab-rail on top (contextual tab first — Notes here, History in Talk — then Voice, Display). Note cards become pure navigation; voice-over / download / reel actions move up to the editor header, always visible for the open note.

Leaning: P2 sub-dock for nav + a slimmed tools-only panel

P2 completes the M2 idea — the strip above the composer is the mode's working set: pinned phrase rows in Talk, note tabs in Notes, prompt pills in Agent. One place to look, one place to tap, editor keeps full width. Overflow past ~5 notes opens a "…" popover with the full previewed list (which is P4's dropdown, demoted to fallback). The right panel stops being navigation anywhere: it becomes a consistent, on-demand toolbox — History · Voice · Display now; Context and Phrases move to the Agent's remit (direct-manipulation phrase editing stays available from the Talk phrase rows). Per-note actions (voice-over · download · reel) live in the editor header, not the panel, so they're visible exactly when the note is. If real usage shows people writing many long notes per space, P3's master-detail is the graceful escalation.
