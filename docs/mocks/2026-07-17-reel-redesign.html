Reel redesign — editorial serif over solid color

Two typographic roles, like a magazine cover: sentence-opening chunks set as a display headline (elegant serif, tight leading) and mid-sentence chunks as support text (Noto Sans bold, smaller). Colors come from Tailwind pairs — a 900/950 background, a 200-tint for the serif, the hue's 50 for support — one pair per reel. Role is derived from punctuation, deterministic, so the DOM player and the canvas MP4 exporter compute the identical sequence. Film grain + soft vignette, no gradients. Font size per chunk comes from the shared pretext fit-and-wrap.

Role rule (shared by player + exporter): a chunk whose previous chunk ended a sentence (. ! ?) renders as Display — serif in the pair's 200 tint, line-height 1.08, active word flips to the 50. Any continuation chunk renders as Support — Noto Sans 700 in the 50, smaller, active word flips to the 200. All colors are stock Tailwind shades (bg 900/950 · display 200 · support 50), so the DOM player uses utility classes and the canvas exporter uses their hex twins. Word states: spoken .55 · active full · unspoken .88. Same pretext binary-search fit, same explicit line breaks, both renderers.
