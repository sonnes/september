Notes as a Markdown document

The note fills the screen as a document. Words go in at the caret, and Markdown shows its format as you write. The suggestion stripes float below the line only while you type, and Esc hides them. The separate composer and "Add to note" go away. Click into the note and type to try it. Select text and press Read aloud to hear only that part.

Present opens the note on the full screen.

The document

  • The title is the first line of the page. It has no field border. The save state and the word count sit below it.
  • The body has no box. It uses the 20px composer size, so the text keeps the size that the user types at today.
  • The Markdown syntax shows only on the line that has the caret. The other lines show the format: headings, bullets, numbers, tasks, quotes, bold, and rules.
  • The note stores plain Markdown in content, as it does today. Read aloud, Present, and Export read the same text.

The stripes

  • The stripes appear on the first key, below the line that has the caret. If the line is near the bottom, they appear above it.
  • A tap on a word puts it at the caret. The return key on a row puts in the full row.
  • Esc hides the stripes. The Hide button does the same for a user who has no keyboard.
  • The style row is at the top of the overlay. A line style (heading, list, checklist, quote) changes the line that has the caret. A second tap removes it. The button of the current style has a highlight.
  • Bold and italic wrap the selected text. With no selection, they wrap the word at the caret.
  • Undo, delete word, and the pinned phrases are in the overlay. The overlay has no clear action, because one tap must not erase a full document.

The note actions

  • Read aloud reads the selected text when there is a selection. Otherwise, it reads the full note. The line that it speaks has a highlight, so the room can follow.
  • Read aloud changes to Stop while it speaks.
  • Present stays one tap away. Export and Delete go into the more menu, because the user needs them less often. Delete is last and red, and it asks for confirmation as it does today.
  • The reading bar shows the Suggestions button too. Thus, a switch user or an eye-gaze user can start to write without a key.
  • The reading bar hides while the stripes are open, so only one floating panel is on the page.

Serif heading with a sans body

The title and the headings use a serif. The body text stays in a sans font for legibility at the 20px note size. Click a card to put the pair in the note.

Font alternatives

Each card shows the same lines at the note size. Click a card or a button above to put that font in the note. The font changes the title and the body only. The tabs, the stripes, and the bar stay in Noto Sans.
