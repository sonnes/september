Mood and audio tags in Talk

Eleven v3 reads short directions in square brackets, such as [laughs] or [whispers]. The voice then laughs, or whispers the words after the tag. In this mock, five emoji set the mood of the conversation. The mood changes the instructions in the suggestion prompt. Tags come inside sentence suggestions and in the word row, so a tag costs one press.

1 · Talk

The mood keys sit in the composer toolbar, left of Audio output. Sentence suggestions carry their tags, and the word row shows tags next to words. Press a mood, a tile, Undo, or Clear. The switch in the header changes the voice model.

Mood

Five emoji keys in the toolbar set the mood of the conversation. Each key has the mood name as its label for screen readers. One press selects a mood. A second press on the same key clears it. The mood stays in the space until the user changes it.

Sentence suggestions

The model writes tags into the suggestion text. Each tag shows as a tile in the row. A press on a tile takes the words and the tags up to that tile.

Word row

The word row shows up to two tag tiles after the words. The tags come from the mood, or from tags that the user sent before. A press adds the tag at the caret.

Other voice models

If the voice model is not Eleven v3, the mood still changes the wording. The prompt then asks for no tags, and the word row shows no tag tiles.

Build note

The composer is a plain textarea today. Chips need a highlight layer behind the textarea. The draft stays one string, with each tag in square brackets.

2 · Mood in the prompt

Each mood adds one block to the user context of the suggestion prompt. The block gives the tone and some example tags. The model can choose any other tag that fits. Without a mood, the prompt has no block.

MoodInstructions in the promptExample tags
Tag rules, added to OPENING_PROMPT and COMPLETION_PROMPT for Eleven v3 onlyYou can add audio tags in square brackets, such as [laughs] or [whispers]. Choose any tag that fits the words. The tags in the mood block are examples only. A tag must describe the voice. Do not use tags for music or sound effects. Put a tag just before or just after the words that it changes. Give a tag only to a suggestion that needs one. Do not change the words that the user typed.

Where the block goes

buildSuggestionPrompt puts the block in <user_context>, after the speaking style. The speaking style stays for every conversation. The mood is for this conversation.

Requests

A change of mood sends a new suggestion request at once. It does not wait for the next word.

Phrases

The phrase prompt does not get the mood. A phrase stays in a space longer than one mood.

Open question

Must the mood clear after a time without messages, for example two hours? If not, the mood stays until the user presses it again.

3 · Sentence suggestions keep their tags

The model writes tags inside the suggestion text. The response format stays a list of strings, so itemsFrom does not change.

That is
laughs thefunniestthingallweek.
anewparkingrecord. giggles
sotypical! sighs
{"suggestions": [ "[laughs] That is the funniest thing all week.", "That is a new parking record. [giggles]", "That is why I stopped driving." ]}

Prefix match

The app removes tags before it compares a suggestion with the typed words. A tag before the typed words does not break the match.

A press takes the tags

A press on a tile takes the words and the tags up to that tile. A tag before the typed words goes to the start of the draft. Undo removes the words and the tags together.

Slices

A tag tile does not count toward the six words of a slice.

History rows

A history row comes from a sent message, so it keeps the tags of that message.

Free choice

The model can write any tag, not only the examples of the mood. The app does not filter tags. Eleven v3 reads tags that are not in its documented list.

4 · Tags in the word row

The word row changes with each letter. It now shows tags as well as words, so a sound is always near the caret.

andbutreallyright laughs giggles
That is so funny

Learning

The local word engine learns tags as tokens from sent messages. If the user often sends "funny [laughs]", the engine shows the laughs tile after "funny".

Mood tags

If the engine has no tag for this place, the row shows the first tags of the mood.

Limit

Tag tiles take at most two of the six places in the row. They always come after the words.

5 · Transcript

A spoken message keeps its tags. The bubble shows each tag as a chip, so the user can see how the message sounded.

ThemI tried to parallel park and hit the same bin twice.
laughsThat is the funniest thing all week.
ThemPlease do not tell Mum.
whispersThat is our secret, then.

Replay

Replay sends the same text with the same tags. The speech cache key uses that text, so a replay plays the saved audio.

Codes

generateCode reads the words only. A tag does not change the code, so "EMI" stays "EMI".

Model-written phrases

PHRASES_SYSTEM_PROMPT can add a tag to a phrase with a clear feeling. It must not add a tag to a neutral phrase, such as "Thank you".

Storage

The tag is part of SavedPhrase.text. The schema and backups do not change.

Mapping

Voice clones

ElevenLabs says professional voice clones are not fully optimized for v3. It recommends an instant clone for v3. The clone sheet on /voice can show the sample tip above.

Open question
