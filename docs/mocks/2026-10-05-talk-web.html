Suggestion Rows

The panel mock draws each suggestion as one sentence. Talk today draws each one as a row of word tiles, and a press on a tile takes the sentence up to that word. The two options below show the same four suggestions.

A. Sentence Rows, as in the Panel Mock

A press on the sentence puts it in the field. The speak key speaks it. The user cannot take only part of a sentence.

Can we move the appointment to Thursday?
Can we try a smaller dose in the morning?
Can we talk about the breathing test?
Can we pause for a moment, please?

B. Word Tiles in the Card

The tiles stay as they are today, inside the card and with the gutter colors. A press on a tile takes the sentence up to that word. Each row is 52 points high and does not wrap.

Open question

Option A has fewer targets and reads faster. Option B keeps the part-sentence take, which saves keystrokes when only the start of a suggestion is correct. The choice applies to the web app and the panel.
